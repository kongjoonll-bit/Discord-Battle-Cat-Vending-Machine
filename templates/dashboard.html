봇 설정

보안상 저장된 토큰은 표시하지 않습니다. 비워두면 기존 값이 유지됩니다.
비밀번호는 해시(PBKDF2)로 저장됩니다. 비워두면 기존 값이 유지됩니다.
아래 은행 알림이 오면 Tasker가 이 주소로 전송합니다. Render 재배포 후 자동 충전이 안 되면 이 URL을 다시 복사해서 Tasker에 갱신하세요 (서버 재시작 시 키가 바뀔 수 있습니다).
충전 신청 후 이 시간이 지나면 요청이 만료되어 자동 충전되지 않습니다. (기본 30분)

입금 계좌 설정

입금 웹훅 수신 로그 Tasker → 서버 수신/처리 기록 (최근 50건)

💡 로그에 %ntitle / %ntext 가 보이면 Tasker 변수가 치환되지 않은 것 → 아래 Tasker 설정 안내를 확인하세요.

웹훅 테스트 — 실제 토스 알림 문구로 파싱/매칭 확인

Tasker(폰) 설정 안내

⚠️ 로그에 %ntitle / %ntext 가 그대로 보이면 Tasker 변수를 잘못 사용한 것입니다. 아래처럼 %evtprm1 / %evtprm2 / %evtprm3 을 사용하세요.

  1. 대시보드 설정 탭 → 📲 입금 자동감지 웹훅 URL 복사
  2. Tasker: + → Event → UI → Notification → 앱 토스 선택, 알림 접근 허용
  3. 작업: + → Net → HTTP Request
  4. Method: POST / URL: 복사한 웹훅 URL
  5. Headers: Content-Type: application/json
  6. Body(아래 그대로): {"title":"%evtprm1","body":"%evtprm2","package":"%evtprm3"}
  7. 저장 후 실제 토스 입금 → 이 탭에서 새로고침 → 로그가 쌓이는지 확인

✅ 자동 충전 조건: ① 충전 신청 대기 ② 토스 알림 도착 ③ 금액+입금자명 일치 — 이 3가지가 모두 충족돼야 충전됩니다.
